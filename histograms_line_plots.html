■ Vocabulary
Key Terms to Know

👆 Click each card to reveal its definition.

📊 Histogram
A bar graph that displays numerical data grouped into equal intervals. Bars always touch — no spaces — because the data is continuous.
📈 Line Plot
A graph showing the frequency of individual data values as dots stacked above a number line. Best for small data sets with a manageable range.
🏔️ Peak
The highest point in a graph — the value or interval that occurs most frequently. A peak shows where data is most concentrated.
🕳️ Gap
A large empty space in a graph where no data values fall. Gaps show intervals or values with a frequency of zero.
🍇 Cluster
A group of data values bunched closely together on a graph. A cluster shows a region where values tend to concentrate.
⭐ Outlier
A data value that is much greater or much less than the majority of other values, standing far away — often separated by a visible gap.
🔔 Normal Distribution
A symmetric, bell-shaped distribution. Data is evenly spread around the centre, with fewer values at the extremes. The left and right sides are mirror images.
🐫 Bimodal
A distribution with two distinct peaks (two modes). Occurs when two different groups within the data each have their own most-common value.
■ Line Plots
What Is a Line Plot?
Definition

A line plot displays the frequency of data values as dots stacked above a number line. Each dot represents one data value.

Best used when: your data set is small and you want to see every individual value, including the exact position of any outliers.
📋 Steps to Create a Line Plot
1
Draw a horizontal number line covering the full range of your data
2
Place a dot above each value — stack dots vertically when a value repeats
3
Label the number line with units and give the graph a descriptive title
Example: Daily Screen Time (hours) — 12 Students

Data: 1, 2, 2, 3, 3, 3, 3, 4, 4, 5, 6, 6

Peak at 3 hours (4 students). Distribution is roughly symmetric.
■ Line Plots
Shapes of Data Distribution
🔔 Symmetric (Normal)

Each side is a mirror image — a bell-curve shape, also called a normal distribution.

📉 Skewed

Data bunches on one side with a long tail on the other. Tail points right = skewed right; tail left = skewed left.

🐫 Bimodal

Two distinct peaks. Often indicates two groups in the data — e.g., Grade 5 and Grade 7 students combined.

■ Line Plots
Features of Distribution
🕳️ Gap

A large empty space where no data values fall — looks like a missing section on the number line.

Example: Students ran 100–150 m or 300–350 m, but nobody ran in between — that middle section is a gap.
🍇 Cluster

A group of values bunched closely together, showing where data concentrates.

Example: Most students are 150–158 cm tall — that height range is a cluster.
⭐ Outlier

A value far from all others, usually separated by a visible gap.

Example: All students jogged 25–45 min, but one jogged 2 hours — that's an outlier!

Spread of Data in a Line Plot
📏 What Is Spread?

The spread shows how far apart the data values range from minimum to maximum.

Range = Maximum − Minimum

■ Histograms
What Is a Histogram?
Definition

A histogram is a bar graph displaying numerical data grouped into equal intervals (called bins). The height of each bar shows the frequency of values in that interval.

Key rule: Bars in a histogram always touch — no gaps between bars, because the data is continuous.

📐 Spread in a Histogram

Because histograms group data into intervals, you can only approximate the range:

Approx. Range = End of Last Interval − Start of First Interval
⚠️ Note: You cannot see exact data values in a histogram — only interval ranges. So the range is always an approximation.
⭐ Outliers in Histograms

Outliers are harder to spot in histograms than in line plots. An isolated bar with very low frequency might contain an outlier — but you cannot see the exact value without the raw data.

The isolated bar at 70–79 (only 1 student) may contain an outlier, but we need the raw data to confirm the exact value.
■ Histograms · Creating
Steps to Create a Histogram
1
Draw and label the axes. X-axis: data values in equal intervals. Y-axis: frequency (count). Give the graph a clear title.
2
Sort the data from least to greatest and calculate the overall range (max − min).
3
Choose equal interval widths — typically 5, 10, or 20 depending on the range. Every value must fall into exactly one interval.
4
Create a frequency table by counting how many values fall in each interval.
5
Draw touching bars to the correct height for each interval. No spaces between bars!
💡 Choosing Interval Width

Use equal intervals that produce about 5–8 bars for a clear graph.

Data RangeSuggested Interval
Up to 505 or 10
50 to 20010 or 20
200 to 100050 or 100
🚫 Common Mistakes
  • Leaving spaces between bars
  • Using unequal interval widths
  • Missing title or axis labels/units
  • Intervals that overlap (a value fits into two bars)
  • Bars that don't start from zero on the y-axis

■ Putting It Together
Line Plot vs. Histogram: When to Use Each
📈 Use a LINE PLOT when...
  • Your data set is small (fewer than ~25 values)
  • You want to see every individual value exactly
  • The range of data is not too large
  • You need to identify outliers at their exact position
  • Example: Scores for 12 students on a short quiz
Remember: Each dot = one exact data value.
📊 Use a HISTOGRAM when...
  • Your data set is large and the range is wide
  • You want to see the overall shape and pattern
  • It makes more sense to group values into intervals
  • You are displaying continuous numerical data
  • Example: Heights of 200 learners at a school
Remember: Each bar covers a range — you cannot see exact values.

■ Real-World Applications
Data in the Real World
🌤️
Weather

Meteorologists use histograms to display temperature distributions over many days. A symmetric histogram suggests a stable climate. A skewed one might indicate unusual heat waves or cold fronts.

Try it: Collect Cape Town's daily max temperature for a month — what shape do you expect?
🏀
Sports

Coaches use line plots to track individual player performance. A skewed result with an outlier could mean one exceptional — or terrible — game. Clusters show consistent performance ranges.

Try it: Record points scored per game by your favourite player across the season.
📱
Technology

App developers use histograms to study daily usage time. A bimodal histogram could reveal two user types — casual users (5 min) and heavy users (2+ hours).

Try it: Check your screen time app — what shape does your usage pattern make?
🔑 Quick Think: Which Graph Is Better?
Scenario A: You want to display the exact number of hours each of your 10 friends slept last night.
→ Line Plot (small data; see exact values)
Scenario B: You want to show the distribution of ages of 800 people at a music festival.
→ Histogram (large data; better grouped into intervals)
■ Summary
Lesson Summary
📈 Line Plots
  • Display individual data values as dots above a number line
  • Best for small data sets
  • Can identify exact outlier values
  • Show shape: symmetric, skewed, bimodal
  • Range = Max − Min (exact value known)
📊 Histograms
  • Display grouped numerical data in touching bars
  • Best for larger data sets with a wide range
  • Cannot see exact values — only intervals
  • Show shape: symmetric, skewed, bimodal
  • Range ≈ End of last interval − Start of first
🔍 Four Features to Identify
🏔️ Peak: highest frequency value/interval
🕳️ Gap: large empty space in data
🍇 Cluster: group of closely bunched values
⭐ Outlier: value far from all others
📐 Distribution Shapes
🔔 Symmetric: mirror image bell shape
📉 Skewed: tail on one side
🐫 Bimodal: two distinct peaks
📈 Normal: symmetric bell curve
